# Findings of the libFuzzer targets (fuzz/) that come from known, unfixed bugs:
# <target> <case pattern>  <ticket>
# A finding is the case '<target>/<signature>', the signature being the
# exception message, sanitizer summary or UBSan error of its reproduction with
# every run of non-alphanumeric characters turned into '-' (e.g.
# 'event_stream_fuzzer/terminate-server_version-...'); the pattern may use '*'.
# A finding listed here is reported as known; any other one is NEW.
# Remove a line once its bug is fixed.
#
# PBS-68 (ticket 1, a FORMAT_DESCRIPTION with an unparsable server version
# terminates the process) and PBS-112 (ticket 39, an invalid event type code
# where the pull sender expects a header) are not listed: the targets filter
# them (fuzz/known_bug_filters.hpp, FUZZ_KEEP_PBS_68 / FUZZ_KEEP_PBS_112) so
# that they do not drown every other finding. A UBSan report in Boost's
# lexical_cast is silenced by fuzz/ubsan_ignorelist.txt.
